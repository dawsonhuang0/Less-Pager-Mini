# og discipleship audit

Walk every commit in `less/.git` in order, oldest first, and adjudicate each
one against our code. **No skipping.** A commit is not "skipped" when it does
not apply to us — it is *adjudicated* and recorded with the reason. Every
commit gets an explicit verdict before the walk moves on.

`commits.tsv` is the ordered list: `index<TAB>sha<TAB>subject`, 3201 entries,
generated by `git -C less log --reverse`.

## Verdicts

| code | meaning |
|---|---|
| `MATCH` | we already implement it; how it was checked is recorded |
| `FIXED` | we diverged; fixed in this repo, with the commit that did it |
| `GAP` | we diverge, not yet fixed — must become an open task, never dropped |
| `N/A` | cannot apply to us, with the reason (Windows/DOS/OS-2 port, build system, docs, upstream test harness, a change later reverted or superseded) |
| `SUPERSEDED` | a later commit in this same walk replaces it; names that commit |

## Rules

1. Read the commit's **full diff**, not its subject. The subject lies by
   omission — see `d0b44fa`, whose subject says "duplicate chars" and whose
   body is the whole atomicity rule for printable representations.
2. `git show <sha> --stat` first: the file list is the checklist of what a
   faithful port has to touch.
3. The commit **message** carries rationale that the code does not. Record it
   when it explains a *why* we would otherwise guess at.
4. A `GAP` is only allowed to be left open with a written reason; it goes in
   the open-gaps section at the bottom of this file.
5. Verify behaviour against the vendored binary (`less/less`, 707x, built from
   this very tree) with the pty differ, not by reading our code and agreeing
   with ourselves.
